## 0. Роль и характер теоремы

A3a — assembly-теорема об артефакте: не новая логика, а доказательство того, что **дисциплина TCG-бандла достаточна** для валидности root-claims (TCG-004 Р2). Логический ингредиент — soundness ARL с непустыми A/C (Lemma 7.2); вклад — теорема уровня сертификата: индукция по trusted-DAG, превращающая множество независимых per-node Accept'ов в семантическую гарантию на композит. Мета-теоремы такого уровня в литературе нет (TCG-004 факт 4).

## 1. Предварительные: ARL по первоисточнику

Фиксируем сигнатуру Σ с сортом Cfg, модель конфигураций 𝒯, множество переменных Var. Паттерны — topmost matching logic (ARL §2).

**П1 (Def 3.1 ARL).** Reachability-система S (правила `φ_l ⇒∃ φ_r`) индуцирует transition-систему (𝒯, ⇒ˢ): γ ⇒ˢ γ′ ⟺ существуют правило и валюация ρ с (γ,ρ) ⊨ φ_l, (γ′,ρ) ⊨ φ_r. **Путь — конечная** последовательность γ₀ ⇒ˢ … ⇒ˢ γ_n; путь **полный** ⟺ не является строгим префиксом другого пути (обрывается в тупике). S **weakly well-defined** (wwd) ⟺ для каждого правила: всякая (γ,ρ), матчащая φ_l, имеет γ′ с (γ′,ρ) ⊨ φ_r.

**П2 (Def 3.2 ARL).** `S ⊨ φ ⇒∀ φ′` ⟺ для всякого **полного** пути τ из γ и всякой ρ с (γ,ρ) ⊨ φ существует γ′ ∈ τ с (γ′,ρ) ⊨ φ′. Расходящиеся исполнения полных путей не порождают — это partial correctness.

**П3 (секвент, Fig. 1 ARL).** Проофсистема выводит `S, A ⊢_C φ ⇒∀ φ′`. A — аксиомы (валидные правила, применимы сразу через Axiom); C — circularities (заявлены, применимы через Axiom только после переноса C→A правилом Transitivity, чья первая посылка при C≠∅ гарантирует ≥1 шаг). **Reflexivity требует C = ∅.** Circularity добавляет текущую цель в C. Оба множества изначально пусты.

**П4 (ступенчатая валидность, §7 ARL).** Для δ ∈ {+, *} и n ∈ ℕ: `S ⊨ₙ^δ φ ⇒∀ φ′` ⟺ для всякого полного пути τ = γ₁…γ_k длины k ≤ n и всякой ρ с (γ₁,ρ) ⊨ φ существует i ∈ {1..k} с (γᵢ,ρ) ⊨ φ′, причём i > 1, если δ = +. `S ⊨ φ⇒∀φ′` ⟺ `S ⊨ₙ* φ⇒∀φ′` для всех n. Обозначим **⊨⁺** := ⊨ₙ⁺ для всех n (строгая валидность: прогресс на всяком полном пути).

**П5 (Lemma 7.2 ARL — несущая).** Если `S, A ⊢_C φ ⇒∀ φ′`, то для любого n: из `S ⊨ₙ⁺ A` и `S ⊨ₙ₋₁⁺ C` следует `S ⊨ₙ* φ ⇒∀ φ′`, а при C ≠ ∅ — `S ⊨ₙ⁺ φ ⇒∀ φ′`. *(Сверено дословно с §7; передача в наших обозначениях.)* Theorem 7.1 — частный случай пустых A/C; soundness механизирована в Coq (клейм статьи; объём покрытия Lemma 7.2 — G-1).

**П6 (Set Circularity, §6 ARL).** Реализация в K доказывает набор claims совместно: C инициализируется всеми claims модуля; Set Circularity сводит валидность каждого к существованию его вывода при таком C. Сопрягается с C9-Q1: kprove-trusted = добавление в тот же circularity-набор без обязательства вывода; step-guard подтверждён (D1 FAILED / D2 PROVED); ложная trusted-лемма принята (конфиг c).

**Замечание Р-1 (немонотонность ⊢ по C).** Добавление элементов в C может разрушить вывод: Reflexivity требует C = ∅. Следствие: вывод узла с локальным C не переносится в объединённый C нескольких узлов ⟹ **ацикличность trusted-DAG несущая** для стратегии сборки (топологический порядок обязан существовать); «слить все узлы в один прогон» — не эквивалентная замена.

**Замечание Р-2 (альтернативная инстанциация для axiom-режима).** *(Смягчено, R2-Low.)* Гипотеза Lemma 7.2 **и для A строгая** (`⊨ₙ⁺`); разница A/C — только индекс (n против n−1). Теорема доказана под H3′ (circularity-режим, зафиксирован C9-Q1). Если бы поведение kprove оказалось axiom-режимом, достаточно заменить H3′ на **H3_A** («Accept(h) = выводы `S, T(h) ⊢_{Own(h)} φ ⇒∀ φ′`») — сборка сохраняется с альтернативной инстанциацией Lemma 7.2 (Л-B, вариант). H5/HJ-класс посылок обязателен в обоих режимах. Риск TCG-004 §5 п.2 форму сборки не меняет.

## 2. Объект: бандл как математическая структура

**Определение 2.1 (бандл, сериальный фрагмент; v1-редакция).** B = (N, E_t, E_c, roots), где:
- N = R ⊎ J: **R-узлы** (reachability) и **J-узлы** (junction/subsumption);
- каждый R-узел h несёт конечное непустое множество **Own(h)** all-path claims над Cfg(S) и свидетельство **Accept(h)**;
- каждый J-узел e несёт импликацию **ψ_e → ψ′_e** и свидетельство entailment-проверки;
- **E_t** ⊆ R × R; **T(h)** := ⋃ {Own(g) | (h,g) ∈ E_t}; **E_c** — рёбра только в J-узлы;
- **roots = roots_R ⊎ roots_asm** *(фикс R2-Medium)*: **roots_R ⊆ R** — root-claims, доказанные одним kprove-прогоном (claim ∈ Own(r) с Accept(r)); **roots_asm** — множество **RootAssembly-записей** (Определение 2.3), каждая декларирует свой целевой claim `φ_a ⇒∀ φ′_a`. Composite-claim по построению не лежит ни в одном Own(h) — иначе он не composite и принадлежит roots_R. J-узел root'ом быть не может. По одному root'у на внешнюю функцию (TCG-003 §5.3).

**Определение 2.2 (что утверждает Accept — содержание H3′).** Accept(h) удостоверяет существование, для каждого φ ⇒∀ φ′ ∈ Own(h), вывода
`S, ∅ ⊢_{Own(h) ∪ T(h)} φ ⇒∀ φ′`
в проофсистеме Fig. 1, где Own(h) ∪ T(h) доступны как step-guarded circularities (П6); элементы T(h) выводов не имеют (C9-Q1, конфиг c). Соответствие «Accept ⟹ вывод существует» — элемент доверенной базы (kprove ∈ T; §6.1).

**Определение 2.3 (RootAssembly-сертификат).** Элемент a ∈ roots_asm — запись, декларирующая целевой claim `φ_a ⇒∀ φ′_a` и его сборку из под-claims (гранулярность C8):
`RootAssembly(a) = [ (φ₀ ⇒∀ ψ₁, h₀); (ψ₁ → χ₁, e₁, σ₁); (χ₁ ⇒∀ ψ₂, h₁); … ; (χ_m ⇒∀ φ′, h_m) ]`
— **линейная** знакочередующаяся цепь: R-claims (каждый ∈ Own(hᵢ) своего R-узла) и J-импликации (каждая — узла eᵢ), с **substitution-witness σᵢ** (явная подстановка/переименование, приводящее Post сегмента i и Pre сегмента i+1 к общим свободным переменным; после применения σᵢ импликация ψ → χ — дословный контент J-узла). Опционально: префиксное ослабление `φ_a → φ₀` и постфиксное усиление `φ′ → φ′_a` — тоже J-узлы. Проверки шага 4 для RootAssembly: цепь синтаксически корректна, все ссылки разрешаются, подстановки применены дословно. Семантическая сила J-свидетельств — не здесь, а в посылке **HJ** (§3.1).

**Замечание о границе v1.** Произвольные (нелинейные) формы графовой сборки root'ов — **вне** объекта теоремы. Это сужение формата, а не проофгэп: G-4 (v1) закрыт ограничением. Расширение форм — вместе с C8.

## 3. Формулировка

### 3.1 Посылки

- **(H1)** B структурно валиден: хеш-дерево сходится; подграф (R, E_t) ацикличен и замкнут; E_c-рёбра ведут только в J-узлы; **roots_R ⊆ R** и достижимы; каждая запись roots_asm — синтаксически корректный RootAssembly (Определение 2.3). (Шаги 1–4 протокола + типизация + проверка цепей.)
- **(H2)** Каждый claim каждого R-узла — all-path (`⇒∀`) claim с **явным** атрибутом в канонической форме (C9-Q2: дефолт v7.1.337 совпадает; носитель — атрибут).
- **(H3′)** Для каждого R-узла h зафиксирован Accept(h) в смысле Определения 2.2 (поведение trusted верифицировано: kprove v7.1.337, report.md Q1).
- **(H4)** (a) Assumptions 1, 2, 4, 6 whitepaper; (b) **A_keccak** — при дизъюнктности слотов; (c) **S weakly well-defined** — assumed/vendored; (d) **A_gas**: всякий →EVM-шаг из конфигурации с конечным газом либо терминален, либо строго уменьшает газ; (e) **A_adm′ (no infinite K-stuttering)**: в каждом →K-пути всякая максимальная серия административных шагов (шагов, не соответствующих →EVM-переходу в смысле Assumption 2) **конечна**. *(Фикс High-2: v1-форма «каждый EVM-шаг симулируется конечным числом K-шагов» слабее используемого в Л-gas — она не исключает бесконечный →K-путь с конечным числом EVM-видимых шагов.)*
- **(H5, структурная)** Цели всех E_t-рёбер — R-узлы; junction/subsumption-претензии не подключаются как trusted. (Механическая проверка шага 4 по ролям узлов и типам свидетельств.) Семантическое ⊨⁺ целей — **выводится** (Следствие 5.2).
- **(HJ, новая — валидность J-свидетельств)** *(фикс R2-High)* Для каждого J-узла e, на который ссылается какой-либо RootAssembly: зафиксирован Accept entailment-чекера, и этот Accept удостоверяет **⊨ ψ_e → ψ′_e** (валидность импликации над моделью 𝒯). Соответствие «Accept чекера ⟹ валидность» — trust-компонент того же класса, что H3′ (§6.1a); replay шага 5 распространяется на entailment-свидетельства. J-узлы, не используемые ни одним RootAssembly, посылок не порождают (Л-J: внутри kprove-прогонов их содержание переустанавливается движком).

### 3.2 Заключение

**Теорема A3a.** При H1–H5:
1. для каждого R-узла h и каждого `φ ⇒∀ φ′ ∈ Own(h)`: **S ⊨⁺ φ ⇒∀ φ′**;
2. каждый root валиден над →K: (i) r ∈ roots_R — из п.1; (ii) a ∈ roots_asm — `S ⊨⁺ φ_a ⇒∀ φ′_a` (при HJ);
3. по Assumptions 1–2 заключение переносится на →EVM; при A_gas и A_adm′ квантификация на →EVM **полная**: «всякий полный путь» = «всякое исполнение».

## 4. Вспомогательные леммы

### Л-B (пер-узловая сборка: Set Circularity с trusted-надбавкой)

**Утверждение.** Пусть для R-узла h: (i) для каждого φ ⇒∀ φ′ ∈ Own(h) существует вывод `S, ∅ ⊢_{Own(h) ∪ T(h)} φ ⇒∀ φ′`; (ii) **S ⊨⁺ T(h)**. Тогда **S ⊨⁺ Own(h)**.

**Доказательство.** C := Own(h) ∪ T(h) ≠ ∅. Сильная индукция по n для `S ⊨ₙ⁺ Own(h)`.
- n = 0: полных путей длины ≤ 0 нет — вакуумно.
- n > 0: по внутренней IH `S ⊨ₙ₋₁⁺ Own(h)`; из (ii) `S ⊨ₙ₋₁⁺ T(h)`; итого `S ⊨ₙ₋₁⁺ C`. Для каждого claim'а применяем **Lemma 7.2 (П5)** с A = ∅ (гипотеза вакуумна): `S ⊨ₙ* φ ⇒∀ φ′`, и при **C ≠ ∅** — `S ⊨ₙ⁺ φ ⇒∀ φ′`. ∎

Прогресс — бесплатный продукт структуры: собственная цель в C (goal-as-own-circularity, стенд T1-Q3) ⟹ Δ_C = + всегда.

**Вариант Р-2 (альтернативная инстанциация под H3_A).** Trusted как A: Lemma 7.2 с A = T(h) (гипотеза `S ⊨ₙ⁺ T(h)` — из (ii)), C = Own(h) ≠ ∅. Заключение идентично. Не утверждается одновременная доказанность под обеими посылками — операционная посылка теоремы одна: H3′.

### Л-T (семантическая транзитивность ⇒∀)

**Утверждение.** Если `S ⊨^δ φ ⇒∀ ψ` (δ ∈ {*, +}) и `S ⊨ ψ ⇒∀ φ′`, то `S ⊨^δ φ ⇒∀ φ′`.

**Доказательство.** Полный путь τ = γ₁…γ_k, (γ₁,ρ) ⊨ φ. По первой посылке — i (i > 1 при δ = +) с (γᵢ,ρ) ⊨ ψ. Суффикс γᵢ…γ_k — полный путь (продолжение суффикса продолжало бы τ). По второй посылке с той же ρ — j ≥ i с (γⱼ,ρ) ⊨ φ′; j > 1 при δ = +. ∎

### Л-C (семантический Consequence)

**Утверждение.** ⊨ φ → φ₁, `S ⊨^δ φ₁ ⇒∀ φ₁′`, ⊨ φ₁′ → φ′ ⟹ `S ⊨^δ φ ⇒∀ φ′`. Прямо по Def 3.2. ∎

### Л-σ (подстановочная устойчивость)

**Утверждение.** Для подстановки σ свободных переменных: `S ⊨^δ φ ⇒∀ φ′` ⟹ `S ⊨^δ φσ ⇒∀ φ′σ`.

**Доказательство.** (γ,ρ) ⊨ φσ ⟺ (γ, ρ∘σ) ⊨ φ (стандартная лемма подстановки FOL/matching logic); квантификация Def 3.2 — по всем ρ. ∎ Л-σ легализует substitution-witnesses σᵢ RootAssembly: сегментные claims применяются в переименованном виде без передоказательства.

### Л-gas (микролемма квантификации — усиленная редакция)

**Утверждение.** При A_gas и A_adm′: из всякой →K-конфигурации, чей →EVM-образ несёт конечный газ, не исходит бесконечных →K-путей. Следовательно, всякое исполнение — префикс полного пути, и квантификация Def 3.2 покрывает все исполнения.

**Доказательство.** Пусть существует бесконечный →K-путь π. Разложим π на максимальные серии административных шагов, разделённые EVM-видимыми шагами. По A_adm′ каждая административная серия конечна ⟹ если EVM-видимых шагов в π конечное число, π конечен после последнего из них — противоречие; значит EVM-видимых шагов бесконечно много ⟹ π проецируется (Assumption 2) в бесконечную →EVM-последовательность ⟹ по A_gas газ строго убывает бесконечно — противоречие с конечностью и неотрицательностью. Конечность всех максимальных путей ⟹ каждый путь продолжается до полного. ∎

**Дельта против v1 (High-2).** v1-форма A_adm («каждый →EVM-шаг симулируется конечным числом →K-шагов») недостаточна: она молчит о →K-хвостах, не соответствующих никакому →EVM-шагу, и о сериях до первого EVM-шага. A_adm′ утверждает ровно используемое: **finite-stutter** на максимальных путях. Разряжение A_adm′ для KEVM — G-5 (терминируемость `#`-конструкций между opcode-шагами).

### Замечание Л-J (роль J-узлов)

J-узлы не порождают посылок Lemma 7.2. Роли: (а) в RootAssembly их импликации — входы Л-C; (б) внутри kprove-прогона та же импликация переустанавливается движком при применении trusted-правила (Axiom + Consequence в выводе Определения 2.2), J-свидетельство корроборативно. Zero-step-претензии не бывают ⊨⁺-валидными (на полном пути длины 1 нет i > 1) ⟹ подключение J-узла как trusted внесло бы в C элемент с ложной гипотезой `⊨ₙ₋₁⁺` — Л-B неприменима. **H5 закрывает hazard структурно.** Эмпирическая сторона (consequence-механика на стенде) — **закрыта кодом** (TCG-006, t1_report; леджер TCG-007 §5: «§6.1/6.2/6.5 закрыты кодом»); защита типизацией сохраняется как design-инвариант, не как страховка от неизвестности. *(Фикс Medium-1.)*

## 5. Доказательство теоремы

### 5.1 Индукция по DAG

(R, E_t) конечен и ацикличен (H1) ⟹ существует топологический порядок.

- **База (листья E_t):** T(h) = ∅; посылка (ii) Л-B вакуумна, (i) — из H3′. Л-B: **S ⊨⁺ Own(h)**.
- **Шаг:** по H5 E_t-дети — R-узлы; по IH S ⊨⁺ Own(g) для каждого ⟹ S ⊨⁺ T(h); (i) — H3′. Л-B: **S ⊨⁺ Own(h)**. ∎ (заключение 1)

**Следствие 5.2 (H5-семантика — выведена).** Каждая цель E_t-ребра ⊨⁺-валидна; прогресс самоподдерживается по DAG (производится C ≠ ∅, не предполагается).

### 5.3 Roots

- **(i) r ∈ roots_R:** из 5.1 напрямую.
- **(ii) a ∈ roots_asm:** индукция по длине цепи Определения 2.3. Каждый R-сегмент `χᵢ ⇒∀ ψᵢ₊₁` — S ⊨⁺ по 5.1, в переименованном σᵢ-виде — по Л-σ; каждая J-импликация валидна **по HJ** (не «по свидетельству» имплицитно — валидность есть содержание посылки); стыковка — Л-T (строгость от первого сегмента: δ = + у головы, хвосту достаточно ⊨*), Pre-ослабление / Post-усиление — Л-C. Итог: `S ⊨⁺ φ_a ⇒∀ φ′_a`. Формы вне Определения 2.3 не покрываются (граница v1, Замечание 2.3). ∎ (заключение 2)

### 5.4 Перенос на →EVM

По Assumption 1 (семантика vendored) и Assumption 2 каждое `S ⊨ φ ⇒∀ φ′` интерпретируется над →EVM; якорение — Assumption 4. По Л-gas (A_gas, A_adm′) квантификация полная. ∎ (заключение 3)

## 6. Доверенная база и границы (что теорема НЕ утверждает)

1. **H3′-соответствие — trust, не вывод.** Форма теоремы: «если Accepts = выводы Fig. 1, то roots валидны». kprove v1 не proof-producing; соответствие несёт T-статус kprove, санируется replay-ем (шаг 5; обоснование — принятие ложной trusted-леммы, C9-Q1 конфиг c). v2 (proof-carrying) заменяет trust на проверку сертификата.
   **(1a) HJ-соответствие — trust того же класса.** Soundness entailment-чекера (Accept ⟹ ⊨ ψ → ψ′ над 𝒯) — вторая trust-строка; несёт SMT-солвер/имплкационный движок; санируется replay-ем; Unknown/Timeout — консервативный отказ, не Accept.
2. **Спецификация ≠ намерение.** Соответствие roots интенту — вне теоремы (H-oracle, D1; blind-spot — A4).
3. **Wwd S — посылка.** Отказной режим: правило с частичной функцией в RHS, не денотирующей при некоторой валюации (родственно `[total]`-обсуждению A5); для KEVM — assumed/vendored; кандидат в общий VO-пул с A5.
4. **A_keccak** — явный вход в T при дизъюнктности слотов.
5. **Реинстанцирование над S′ (для A3b) — условное, по A5 v3.** *(Фикс Medium-2.)* Сборка §5 параметрична по семантике (использует только wwd + Lemma 7.2 + Def 3.1/3.2) и реинстанцируется над transition-системой **(Cfg_wf(S′), →_{S′})** — well-formed конфигурации, **нормализованное** отношение (A5 §1.1/1.3) — при условиях:
   - wwd S′ на wf-домене: сводится к wwd S + корректности GF-нормализации (A5 Л-GF/NF) — упирается в **VO-GF/NF**;
   - остаточные обязательства A5: **VO-K** (transition/equational-разделение), **VO-2p**, **VO-6p**;
   - claims — под **wf-дисциплиной C1/C6**: ghost-паттерны Pre wf-констрейнены, ghost-переменные свежие и попарно независимые;
   - замкнутость путей в Cfg_wf — A5-0.
   Перенос на →EVM — **только для не-ghost наблюдаемых**, через композицию A5-C3 с Assumption 1; ghost-содержание claims (значения `<inFunc>` и т.п.) на →EVM не переносится — его связь с реальностью несёт INV_inFunc (посылка A3b, не A5 и не A3a). Потребитель — ветка 3; нести ссылкой на этот пункт, не передоказывать.
