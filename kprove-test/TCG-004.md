## 1. Принятые факты (из literature map, первоисточники)

Полные цитаты и уверенность — в literature_map_A3a_A3b.md. Здесь — только то, что несёт решения.

1. **Квантор — атрибут claim, не свойство системы.** K-claim бывает `⇒∀` (all-path: «любая конфигурация из φ на *любом полном* пути достигает φ′») и `⇒∃` (one-path). Нашей Теореме 1 соответствует строго `⇒∀`. Проофсистема ARL **sound (partial correctness) и относительно полна, soundness механизирована в Coq**. [Ștefănescu et al., ARL, LMCS 15(2:5) 2019; K User Manual]
2. **ARL уже параметризована аксиомами.** Правило Circularity: «circularities C … используются только после шагов исполнения по правилам из **S или A**» — валидные правила применимы как аксиомы. Circularity (step-guarded, для самоиспользования в ходе доказательства) и trusted-как-аксиома (готовая лемма) — **разные механизмы**. [ARL §4; haskell-backend issue #1277]
3. **Противоречие документации:** K-манул описывает `trusted` как «добавить в список proven **circularities**», issue #1277 — «**NOT** as circularity rules». Манул не цитировать; поведение проверять кодом (→ C9). [K User Manual vs issue #1277]
4. **Мета-теоремы «бандл ⟹ валидность roots» в литературе нет** — ни conservative-extension-леммы для claim-as-axiom, ни композиционного результата уровня артефакта. Ниша A3a. [literature map, P0.2]
5. **Exit — нативен:** `<statusCode>` — штатная ячейка спеков (deposit-спека целиком «reverts when …»). **Trace промежуточных состояний — не помещается** в одиночный `⇒∀`-claim (claim связывает две конфигурации); путь — ghost/monitor-ячейка, расширение логики не требуется. [verified-smart-contracts, spec-tmpl.k]
6. **KEVM не несёт инъективности keccak** — только range-леммы `0 ≤ keccak(_) < pow256` (проверено в lemmas.k). Дизъюнктность слотов — общепринятое модельное допущение (Certora — allocation/storage splitting). [evm-semantics lemmas.k]
7. **Дихотомия «подавление vs композиция» подтверждена по всем четырём соседям:** ECF (эквивалентность callback-free трейсу), VerX (EECF-допущение), SeRIF (типизация доверия), Scilla (устранение call-and-return) — все **подавляют** интерференцию. R/G / separation / footprint **над EVM-байткодом не найдено** (~10 целевых запросов, ключи зафиксированы в map). Ближайший сосед по духу сертификата — TCT (arXiv:2408.06478), runtime-checked. [literature map, P1.4–P1.5]
8. **Прецедент Guar_env:** враждебное окружение моделируется над-аппроксимирующими символьными правилами (`[trusted]`-правила deposit с символьным выходом; havoc/dispatcher); переиспользуемого env-узла в литературе нет. [abstract-semantics.k; map P2.b]

## 2. Решения

**Р1. All-path — machine-checkable посылка формата.**
Атрибут `all-path` обязателен для каждого claim в graph.json. Проверка атрибута — новая структурная проверка шага 4 протокола. `--default-claim-type` реальных спеков проверяется в C9. Каноническая форма (C6) обязана сохранять квантор — сериализация, теряющая атрибут, дисквалифицирована.

**Р2. A3a — assembly-теорема об артефакте.**
Логический ингредиент существует (ARL-soundness с аксиомами, Coq); наш вклад — теорема уровня сертификата: индукция по топологическому порядку trusted-DAG со ссылкой на ARL-soundness в шаге. Честная формулировка новизны: «не новая логика — доказательство того, что дисциплина бандла достаточна». C9 теперь проверяет **применимость** этого доказательства: если kprove применяет trusted как circularities (по манулу), а не как аксиомы (по issue), шаг индукции требует другой леммы.

**Р3. C7 — ghost-монитор; новая лемма прозрачности (A5).**
Exit закрывается нативно. Trace-инварианты — ghost-ячейкой, аккумулирующей события (вызовы, повторные входы), с утверждением в Post. Цена: claims доказываются против инструментированной семантики S′ → **A5: проекция S′ на не-ghost ячейки бисимулярна S** (доказывается один раз, охраняет перенос Assumption 1). Без A5 инструментация — тихий разрыв доверенной базы.

**Р4. A_keccak — в Aasm-леджер.**
`инъективность keccak на использованных прообразах` — явный вход в T (annotations.json), обоснование: KEVM proof отсутствует (факт 6), допущение индустриально стандартно. Footprint-триаж A3b (синтаксическая дизъюнктность) явно помечается как «под A_keccak».

**Р5. Рамка новизны A3b — цитируемая дихотомия.**
Формулировка для paper: «состояние области — *подавление* интерференции (допущением: ECF/EECF; типами: SeRIF; языком: Scilla); A3b — первая дисциплина, *композирующая* интерференцию на уровне байткод-семантики через явные rely/guarantee». TCT — в related work бандла (A2): runtime-checked theorems против нашего static-сертификата.

**Р6. Guar_env — над-аппроксимирующее символьное правило.**
Env-узел = «любой переход, допустимый семантикой EVM и не заблокированный access control субъектов», в KEVM-стиле `[trusted]`-правил с символьным эффектом. Отсутствие прецедента переиспользуемого env-узла — часть вклада A3b.

## 3. Постулаты теорем

### Теорема A3a (soundness бандла, последовательный фрагмент)

**Посылки:**
- **(H1)** Бандл структурно валиден (шаги 1–4 протокола TCG-003 §6): хеш-дерево сходится; DAG trusted-рёбер ацикличен и замкнут; roots достижимы.
- **(H2)** Каждый claim каждого узла — **all-path** (`⇒∀`) reachability claim над конфигурациями KEVM.
- **(H3)** Для каждого узла h зафиксирован Accept kprove против теории S ∪ A(h), где A(h) — claims детей h по trusted-рёбрам, применённые **как аксиомы, не как circularities**.
- **(H4)** Assumptions 1, 2, 4, 6 whitepaper; **A_keccak**, если использована дизъюнктность слотов.

**Заключение:** каждый root-claim валиден над →K: из любой конфигурации, удовлетворяющей Pre, всякий полный путь удовлетворяет Post и Exit. По Assumptions 1–2 заключение переносится на →EVM.

**Схема доказательства:** индукция по топологическому порядку trusted-DAG. База: листья доказаны против S — валидность по ARL-soundness (механизирована в Coq). Шаг: узел доказан против S ∪ A(h), все элементы A(h) валидны по IH — валидность по ARL-soundness с валидными аксиомами.

**Замечание (EVM-специфика):** оговорка ARL «только полные (терминирующие) пути» на EVM ничего не ограничивает: газ делает все пути конечными; квантификация фактически полная.

**Статус:** все посылки подтверждены первоисточниками; готова к написанию. Единственный внешний риск — H3 против реального поведения kprove (C9).

### Теорема A3b (интерферирующий фрагмент — постулат)

Формулируется над S′ = S + ghost-монитор, **при доказанной A5**.

**Посылки:**
- **(H1–H4)** посылки A3a над S′.
- **(H5)** Каждый loop i несёт интерфейс `(Preᵢ, Postᵢ, Exitᵢ, Foot_rᵢ, Foot_wᵢ, Relyᵢ, Guarᵢ)`; frame-claim «записи bᵢ ⊆ Foot_wᵢ» доказан.
- **(H6)** Для каждой пары i≠j с пересекающимися footprint — compat-claims `Guarⱼ ⟹ Relyᵢ` и `Guarᵢ ⟹ Relyⱼ` доказаны; для непересекающихся — синтаксическая дизъюнктность (**под A_keccak**).
- **(H7)** Env-узел присутствует; Guar_env — над-аппроксимация произвольного EVM-кода (Р6); compat каждого loop против env доказаны.
- **(H8)** Relyᵢ требуется только в **точках приостановки**: границы транзакций и сайты внешних вызовов (последовательность EVM: истинного параллелизма нет, интерференция синтаксически локализована).

**Заключение:** конъюнкция локальных trace-инвариантов (в ghost-форме) держится на всяком интерливинге транзакций и повторных входов.

**План доказательства:** индукция по последовательности точек приостановки; PAR-правило Jones/RGSim («guarantee одного влечёт rely другого»), адаптированное к последовательному EVM с синтаксическими suspension points.

**Статус:** постулат; доказательство — основное содержание A3b. Зависимости: A5, реализация ghost-монитора (C7-остаток), формулировка Guar_env.

## 5. Открытое

1. **Fig. 1 ARL глазами:** точная параметризация проофсистемы аксиомами A и формулировка soundness с A процитирована косвенно («S or A» в правиле Circularity). Прочитать до написания A3a; если аксиомы устроены иначе — шаг индукции требует собственной леммы (объём растёт, защитимость не падает).
2. **C9 (обострён):** поведение trusted в текущем kprove — аксиома на старте или circularity. Решает применимость доказательства A3a as-is.
3. **Реализуемость ghost-монитора** в KEVM extension-модулем, без правки основной семантики — не проверена; C9-класс.
4. **Формулировка Guar_env:** самая скользкая часть A3b (ошибка = unsoundness всей параллельной части); отдельная проработка до доказательства.
5. **VerX/EECF:** уверенность indirect (текст закрыт издателем); в related work опираться на ECF-линию (POPL 2018), не на точную цитату VerX.
6. **Гранулярность footprint для маппингов:** статическая дизъюнктность классов слотов может требовать символьной проверки даже в «дешёвом» триаже; не проработано (перенесено из сессии по параллельной композиции).

## 6. Итог

- **A3 расщеплён и постулирован:** A3a — assembly-теорема, готова к написанию; A3b — R/G-program с подтверждённой границей новизны.
- **Формат дополнен** без ревизии скелета: атрибут квантора, типизация рёбер, три роли узлов, две новые посылки + A5.
- **Очередь:** C9 (применимость H3) → чтение ARL Fig. 1 → написание A3a → A5 + C7-остаток → A3b.
