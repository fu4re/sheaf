# Finding 0001 — Реализм агентской генерации экономических спек (Aave Vault)

- **Дата:** 2026-06-22 · **Тип:** эмпирический замер (один прогон, pilot)
- **TL;DR:** на реальном `ATokenVault.deposit` агент покрыл **≈64%** доказанных
  экспертных экономических инвариантов Certora в один shot. Главное не число, а
  **характер промахов: они структурные (выразительность языка), а не случайные.**

---

## Сетап (воспроизводимый)

| | |
|---|---|
| Цель | `aave/Aave-Vault` @ `5ab52d2`, метод `ATokenVault.deposit` (fees, yield-accrual, aToken-rebase, округление) |

## Результат

Агент предложил **8** инвариантов. Против 7 экспертных:

| Экспертный инвариант (Certora, доказан) | Статус |
|---|---|
| `totalSupply!=0 ⇒ totalAssets!=0` (солвентность) | ✅ recovered (почти дословно) |
| `claimableFees ≤ aToken.balanceOf(vault)` (fee-backing) | ✅ recovered (дословно) |
| `lastVaultBalance ≤ aToken.balanceOf(vault)` | ✅ recovered (дословно) |
| `balanceOf(u) ≤ totalSupply` | ✅ recovered |
| `sumAllBalance() == totalSupply()` (конс. долей) | 🟡 partial — дал корролярий, не сумму |
| `accumulatedFees` монотонно не убывает | ❌ missed |
| изменение баланса ⇒ accrual | ❌ missed |

**recovered 4 · partial 1 · missed 2 ≈ 64%.** Плюс 4 инварианта **сверх** набора.

## Ключевая находка: промахи структурные, не случайные

Агент промахнулся ровно по тем свойствам, которые **невыразимы в его выходном языке**
(одна Solidity-строка над текущим состоянием). Это **пробел выразительности, а не знаний**:

1. **Квантифицированные.** `sumAllBalance() == totalSupply()` требует ghost-суммы по
   mapping (Certora ведёт её ghost-переменной с hook'ами). В plain-Solidity невыразимо —
   агент выдал максимум выразимого (`balanceOf(u) ≤ totalSupply`).
2. **Темпоральные / 2-state.** Монотонность fees и «изменение баланса ⇒ accrual» нужны
   `old()`/pre-post. Шейп инварианта одного состояния их не выражает.

**Вывод:** разрыв закрывается не «более умной моделью», а **расширением DSL инварианта**
(ghost-сумма по mapping + форма `old()`/2-state).

## Вторичные наблюдения

- **Over-generation (coverage > precision)** — профиль PropertyGPT: 8 предложено, 4
  экспертных покрыто, 4 сверх. Часть избыточна → нужен символьный фильтр.
- **Один extra сильнее эксперта:** `aToken.balanceOf(vault) == totalAssets() + claimableFees`
  — агент поднял в инвариант само определение `totalAssets()` из кода.
- **Агент сам потянулся к нелинейному** `shares_backed_proportionally` (`mulDiv`) — это
  стена *доказательства* (нужна ghost-аксиома арифметики), не генерации.

## Импликации для дискуссии

- **«Спека = экономика» генерится агентом реалистично** на stateless-слое (≈эксперт).
- **Узкое место смещено в две конкретные точки:** (а) выразимость quantified/temporal
  инвариантов, (б) **proof harness** (ghost-арифметика) — отдельно от генерации,
  подтверждённая в этом же цикле стена.
- Согласуется с тезисом «moat не в генерации инвариантов (≈решено), а в proof harness
  и курировании».

## Честные оговорки

- **Один прогон.** Стохастика не измерялась → 64% это точечная оценка, не распределение.
  N прогонов + voting сдвинут число (вероятно вверх).
- **Судья — сам LLM** → субъективность recovered/partial/missed. Усиление: проверять
  «recovered» **солвером** на логическую эквивалентность.
- Мерили **только генерацию**, не доказуемость. Доказать эти инварианты на Aave — отдельная
  (известная) стена `rayMul`/`rayDiv`.
- Покрытие против дистиллированных 7 свойств; функциональные/rounding (`erc4626.spec`)
  исключены как не-экономические.
